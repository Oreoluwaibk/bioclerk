# BioClerk

Marketing site for [BioClerk](https://bioclerk.com/), an offline clinical dictation app. Speech is turned into text on the device. The site explains the product and links to the Windows, Android, and browser-extension downloads.

## Stack

Next.js (App Router), React, TypeScript, and Tailwind CSS.

## Pages

| Path | What it is |
| --- | --- |
| `/` | Product home |
| `/privacy` | Privacy policy |
| `/terms` | Terms of use, including the MedASR notice |

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`npm run build` then `npm start` runs the production server. `npm run lint` checks the project.
